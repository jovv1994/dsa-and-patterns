# DSA and Coding Interview Patterns

A language-agnostic study repository for **Data Structures, Algorithms, and Coding Interview Patterns**.

Solutions and notes are provided in both **Java** and **Python**.

---

## Purpose

This repository organises interview preparation by *algorithmic pattern* rather than by data type. Recognising the underlying pattern of a problem is the fastest path to a correct solution under time pressure.

---

## How to Use

1. Read a pattern's `README.md` to understand the technique, when to apply it, and its complexity profile.
2. Browse the `java/` or `python/` sub-folder for concrete implementations and worked examples.
3. Consult the `notes/` folder for general complexity references and language-specific tips.
