# Pattern 01 - Iteration

## Definition

Iteration consists of traversing a data structure sequentially to inspect or process each element.

---

## When to use

Use this pattern when you need to:

- Visit every element.
- Count elements.
- Print values.
- Compare characters or numbers.
- Build a new result while traversing.

---

## Common Data Structures

- String
- Array
- List

---

## Typical Complexity

Time: O(n)

Space: O(1)

---

## Recognition Clues

- "Traverse the string."
