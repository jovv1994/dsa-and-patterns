# Count Vowels

## Difficulty

Easy

---

## Problem

Count how many vowels exist in a string.

Example

Input

hello world

Output

3

---

## Pattern

Iteration

---

## Recognition

The problem requires visiting every character exactly once.

---

## Data Structures

- String

---

## Algorithm

1. Create a counter.
2. Traverse the string.
3. Check whether each character is a vowel.
4. Increment the counter.
5. Return the counter.

---

## Complexity

Time: O(n)

Space: O(1)

---

## Lessons Learned

- Strings are immutable.
- charAt(i) returns the character at index i.
- Declare temporary variables inside the loop if they are only used there.
